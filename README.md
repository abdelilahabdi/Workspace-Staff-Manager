# Workspace-Staff-Manager

Présentation du projet Worksphere

Worksphere est une application web responsive destinée à faciliter la gestion des employés au sein d’un espace professionnel grâce à une visualisation interactive du plan des locaux.
L’utilisateur peut manipuler les éléments du plan en ajoutant, déplaçant ou supprimant des employés, tout en respectant des règles métier prédéfinies :

certaines zones sont réservées à des rôles spécifiques (ex. : seuls les réceptionnistes à l’accueil, les techniciens IT dans la salle des serveurs),

chaque espace possède des contraintes de capacité et d’accès.

Chaque membre du personnel est associé à un profil complet accessible directement depuis le plan : photo, fonction, coordonnées, expériences, etc.

L’interface est développée avec des technologies front-end modernes (HTML, CSS via Flexbox/Grid, animations), offrant une navigation fluide sur ordinateur, tablette et mobile. Le projet peut être déployé aisément sur GitHub Pages, Vercel ou toute autre solution d’hébergement web.
